# プライバシーポリシー

[English version is available here / 英語版はこちら](./privacy-policy.en.md)

マージナルゲイン株式会社（以下「弊社」）は、以下のプライバシーポリシーに従って、お客様よりご提供いただく個人情報（以下「本個人情報」）を厳重に管理しております。本ポリシーは、弊社のウェブサイトおよび弊社が提供するモバイルアプリ（以下「本アプリ」）に適用されます。

## 法令の遵守

弊社は、本個人情報の取得、利用、その他の取り扱いについて、個人情報の保護に関する法律その他の適用法令及びこのプライバシーポリシーを遵守します。

## 本個人情報とは

本個人情報とは、お客様が弊社製品およびサービスのご利用を通じてご提供いただく個人に関する情報で、氏名、性別、生年月日、年齢、職業、郵便番号、住所、メールアドレス、電話番号、FAX番号、その他の記述により個人を識別もしくは特定できる情報です。統計的に処理した情報など、個人を特定できない情報は個人情報とはみなしません。

## 本個人情報を取得する目的

弊社では、以下の目的の為に本個人情報を取得することがあります。以下に定める目的以外に利用する場合、本個人情報取得の際に個別に公表又は通知します。

- お客様が利用されるサービスの提供
- サービスの利用及びご購入いただいた製品のサポート及びお知らせ
- キャンペーン等の商品発送のため

## モバイルアプリで収集される情報

本アプリは、アプリ自体がお客様の個人情報を収集・送信しない設計としています。アプリごとに特に記載がない限り、アカウント登録は不要であり、アプリ内で入力・生成された情報はお客様の端末内で処理・保存されます。

### 広告について

一部の本アプリでは、Google LLC が提供する第三者広告サービス「Google AdMob」による広告を表示します。広告配信に関連して、AdMob SDK が以下のような端末情報を自動的に収集し Google に送信することがあります。

- 広告識別子（Android 広告 ID、Apple IDFA など）
- 端末情報（端末モデル、OS バージョン、言語設定など）
- IP アドレスから推定されるおおよその位置情報
- 広告の表示・タップなどの操作情報

これらの情報は、広告配信・広告効果測定・不正防止などの目的で Google により利用されます。Google による情報の取り扱いの詳細は以下をご参照ください。

- Google プライバシーポリシー: <https://policies.google.com/privacy>
- Google による広告データの利用: <https://policies.google.com/technologies/ads>

### パーソナライズ広告への同意

法令により同意が必要な地域（欧州経済領域・英国・スイスなど）のお客様には、アプリ起動時に Google の User Messaging Platform（UMP）が提供する同意フォームを通じて、パーソナライズ広告の配信に関する同意を取得します。選択内容は、アプリ内の設定やメニュー（提供されている場合）からいつでも変更できます。

また、端末の設定（Android の「広告 ID を削除」、iOS の「App からのトラッキング要求を許可」など）により、広告識別子の利用を制限・リセットすることもできます。

### 利用状況の分析とクラッシュレポート

一部の本アプリでは、アプリの利用状況の把握と安定性の改善のため、Google LLC が提供する「Google Analytics for Firebase」および「Firebase Crashlytics」を使用しています。これらのサービスに関連して、以下のような情報が自動的に収集され Google に送信されることがあります。

- アプリの操作情報（画面表示、セッション数、アプリ内イベントなど）
- クラッシュログ（スタックトレース、クラッシュ発生時のアプリ・端末の状態など）
- 端末情報（端末モデル、OS バージョン、言語設定など）
- アプリのインストールごとに割り当てられる識別子（アプリインスタンス ID、インストール単位の UUID など。これらはお客様個人を特定するものではありません）
- マスク（切り詰め）された IP アドレスから推定されるおおよその位置情報

これらの情報は統計的に処理された形で利用分析・クラッシュ診断に用いられ、弊社が個人を特定する目的で利用することはありません。情報は転送時に暗号化されます。Google による情報の取り扱いの詳細は以下をご参照ください。

- Firebase におけるプライバシーとセキュリティ: <https://firebase.google.com/support/privacy>

### 本アプリを通じてアクセスする第三者ネットワーク

一部の本アプリは、第三者が提供する Wi-Fi ネットワークへの接続を支援するものであり、そのネットワークのログイン（キャプティブポータル）ページを表示することがあります。ログインページでお客様が入力した情報は、当該ネットワーク提供者へ直接送信され、弊社が取得することはありません。当該情報の取り扱いは、各ネットワーク提供者のプライバシーポリシーに従います。

## 保存期間

弊社は、利用目的に必要な範囲で本個人情報の保存期間を定め、保存期間経過後又は利用目的達成後に本個人情報を消去又は廃棄します。

## 第三者への開示

弊社は、以下の場合を除き、お客様の同意を得ることなく本個人情報を第三者に開示又は提供しません。

- 企業が従うべき法的義務遂行のために必要な場合
- 統計的に処理されたデータなど、個人を特定できない情報を開示する場合
- 弊社の業務委託先または業務提携先に、事前に秘密保持契約を締結した上で、サービスの利便性向上のために必要最小限の範囲内で開示する場合

なお、上記「モバイルアプリで収集される情報」に記載のとおり、第三者の広告・分析・クラッシュレポート SDK が収集する端末情報は、当該第三者（Google）に直接送信され、その第三者のプライバシーポリシーに従って取り扱われます。

## 国外へのデータ移転

弊社は日本に所在し、弊社が収集する本個人情報は日本国内で処理されます。Google AdMob、Google Analytics for Firebase、Firebase Crashlytics などの第三者サービスが収集する情報は、各サービスのプライバシーポリシーに従い、各国に所在するサーバーで処理されることがあります。

## クッキー（Cookie）の取り扱い

弊社では、当社のウェブサイトにおいて、クッキー（Cookie）、Web ビーコン（Web Beacon）その他の類似技術を用いることがあります。いずれの場合も、収集される情報に新たな個人情報は含まれませんが、既にご提供いただいている本個人情報と関連付けて利用する場合があります。お客様は、ご利用のブラウザの機能により、保存されたクッキーを削除する、クッキーを受け容れない、等を設定できます。但し、保存されたクッキーを削除した場合やクッキーの機能を無効とする設定を選択した場合、一部機能に制約が生じる可能性があります。

## 安全管理措置

弊社は、本個人情報の漏洩、滅失及び毀損を防ぐため、必要かつ適切な安全管理措置を講じるとともに、その改善に努めます。

## 継続的取り組み

弊社は、本個人情報の取り扱いにつき、内部規程の整備や見直し、教育の実施等を通じ、継続的な改善に努めます。

## お客様の権利（開示・訂正および削除）

お客様が弊社に提供されました個人情報につき、開示・訂正・追加・削除の必要性が生じた場合には、お手数をかけますが、お客様ご本人よりお問合せページまたは該当アプリのストアページに記載の連絡先からお申し出ください。お客様の国・地域の法令（EU 一般データ保護規則など）により、処理の制限、データポータビリティ、異議申立て、監督機関への苦情申立てなどの権利を有する場合があります。弊社は適用法令に従い対応します。

本アプリ自体はお客様の個人データを保持しないため、アプリ内で作成されたデータはアプリのデータ削除またはアンインストールにより削除できます。第三者の広告・分析サービスが収集した情報の削除については、各サービスのプライバシーポリシーおよび端末の設定をご参照ください。

## 本ポリシーの変更

弊社は、法令の改正やサービスの変更等に応じて、必要に応じて本ポリシーを改定することがあります。重要な変更を行う場合は、弊社ウェブサイトまたは該当アプリ内でお知らせします。
