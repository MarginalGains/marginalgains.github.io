# Suihei(水平補正ツール)プライバシーポリシー

[English version is available here / 英語版はこちら](./privacy-policy.en.md)

マージナルゲイン株式会社(以下「当社」といいます。)は、当社が提供する macOS 向けアプリケーション「Suihei(水平補正ツール)」(以下「本アプリ」といいます。配信ストアまたは表示言語により、ローカライズされた名称で表示されることがあります。)について、お客様のプライバシーを尊重し、以下のプライバシーポリシー(以下「本ポリシー」といいます。)に従って情報を取り扱います。

本ポリシーは本アプリに固有の取り扱いを定めるものです。当社のウェブサイトおよび当社が提供するその他のサービスには、別途、当社の[共通プライバシーポリシー](../privacy-policy.md)が適用されます。本ポリシーに定めのない事項は、共通プライバシーポリシーおよび適用法令に従います。

## 1. 基本方針

本アプリは、写真の傾きを補正(回転・クロップ)するための端末上で完結するツールであり、**お客様の個人情報を収集・送信しない設計**としています。本アプリの利用にあたってアカウント登録は不要であり、本アプリが処理する写真その他のデータは、お客様の端末内でのみ処理・保存されます。本アプリは、その動作のためにインターネット通信を行いません。

## 2. 当社が取得する個人情報

当社は、本アプリを通じて、お客様の個人情報を取得しません。具体的には次のとおりです。

- **写真・画像データ**: 本アプリが読み込む写真および画像は、補正処理(傾き推定・回転・クロップ・書き出し)のためにお客様の端末内でのみ処理されます。当社のサーバーその他の外部に送信されることはありません。本アプリは元のファイルを変更しない非破壊設計であり、補正結果はお客様が指定した出力先にのみ書き出されます。
- **編集状態・設定データ**: 編集セッション(補正値・クロップ範囲等)やアプリの設定は、お客様の端末内のアプリ領域(アプリケーションサポートフォルダ等)に保存されます。これらは当社が取得することはありません。
- **ファイルへのアクセス権**: 本アプリは macOS の App Sandbox 下で動作し、お客様が選択したフォルダ・ファイルにのみアクセスします。再起動後の自動復元のために、お客様が許可した範囲のアクセス権(security-scoped bookmark)を端末内に保存します。

当社は、Apple から、個人を特定できない統計的な販売情報(国・地域別の販売数、売上集計等)を受け取ることがありますが、これによって個々のお客様を特定することはできません。

- Apple のプライバシーポリシー: <https://www.apple.com/legal/privacy/>

## 4. 分析・クラッシュレポート・広告について

- 本アプリは、第三者が提供する**分析(アナリティクス)SDK、クラッシュレポート SDK、および広告 SDK を一切組み込んでいません**。本アプリは広告を表示しません。
- お客様が OS(Apple)の機能を通じて診断・使用状況データの共有に同意している場合に限り、Apple がクラッシュ情報や使用状況データを収集し、当社はそれを**集約・匿名化された形**で参照することがあります。これらの情報は本アプリが独自に送信するものではなく、Apple の管理のもとで取り扱われます。共有の可否は、お客様の端末の設定(プライバシーとセキュリティ → 解析と改善 等)からいつでも変更できます。

## 5. 第三者への提供

当社は、本アプリを通じてお客様の個人情報を取得しないため、第三者に提供する個人情報を保有しません。前項までに記載のとおり、Apple を通じた取引に関する情報は Apple が、お客様の同意に基づく診断情報は Apple が、それぞれのプライバシーポリシーに従って取り扱います。

## 6. 国外へのデータ移転

当社は日本に所在します。本アプリはお客様の端末外に個人情報を送信しないため、当社による国外へのデータ移転は生じません。Apple を通じた取引・診断に関する情報は、Apple のプライバシーポリシーに従い、各国に所在するサーバーで処理されることがあります。

本アプリは、お客様のデータを端末内で処理し外部に送信しない設計とすることで、情報漏えいの危険を構造的に低減しています。当社は、本アプリの開発・配信にあたり、必要かつ適切な安全管理措置を講じるよう努めます。
