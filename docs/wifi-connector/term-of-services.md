# Wi-Fi Connect 利用規約

[English version is available here / 英語版はこちら](./term-of-services.en.md)

## 第2条(定義)

本規約において使用する以下の用語は、以下の各号に定める意味を有するものとします。

(1) 「本アプリ」:スマートフォン向けアプリケーション「Wi-Fi Connect」(Android版及びiOS版を含みます。配信地域、配信ストアまたは表示言語により「Wi-Fi接続サポート」「Wi-Fi Connection Helper」その他のローカライズされた名称で表示されることがあります。)

(2) 「本サービス」:本アプリを通じて当社がユーザーに提供する一切のサービス(キャプティブポータルの表示支援、接続状態の診断及び設定の案内等)

(3) 「ユーザー」:本規約に同意し、本サービスを利用する個人

(4) 「対象ネットワーク」:ユーザーが接続を試みるWi-Fiネットワーク

(5) 「ネットワーク提供者」:対象ネットワークを設置、提供または運営する当社以外の第三者

(6) 「キャプティブポータル」:対象ネットワークの利用開始にあたりネットワーク提供者が表示するログイン・認証・規約同意等のためのウェブページ

## 第3条(本サービスの内容)

ユーザーは、当社が定める方法に従い、本サービスを利用することができます。本サービスの利用にあたり、アカウント登録は不要です。

本サービスには、以下の機能が含まれます。

(1) 対象ネットワークのキャプティブポータルを本アプリ内に表示し、ユーザーによる規約への同意・ログイン等の操作を支援する機能(以下「接続支援機能」といいます。)

(2) プライベートDNS、VPNその他接続の妨げとなり得る端末の設定や状態を検出し、確認すべき設定をユーザーに案内する機能(以下「診断機能」といいます。)

(3) ローカルIPアドレス、ゲートウェイIPアドレス、DNSサーバー、OSによるキャプティブポータル判定その他の接続状態に関する情報を表示する機能

当社は、ユーザーへの事前の通知なく、本サービスの内容、仕様を変更し、またはその提供を停止もしくは中止することができるものとします。
